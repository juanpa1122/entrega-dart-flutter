# Configuración de Flutter y Android

- Flutter SDK instalado y agregado al PATH.
- Extensiones Dart y Flutter instaladas en Visual Studio Code.
- Android SDK y herramientas de línea de comandos configuradas.
- Licencias de Android aceptadas.
- Entorno verificado mediante `flutter doctor -v`.
- Depuración USB activada.
- Dispositivo físico SM S938B reconocido mediante `flutter devices`.
